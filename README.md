## Overview

This project transforms Brazilian e-commerce data into meaningful business insights through interactive visualizations, key performance indicators (KPIs), and analytical reports.

## Features

- **Executive Overview:** Overall business performance and key metrics.
- **Sales Analytics:** Revenue trends, order volume, and sales performance.
- **Customer Analytics:** Customer distribution and purchasing behavior.
- **Delivery Operations:** Delivery performance and delays.
- **Customer Satisfaction:** Review scores and customer feedback.
- **Payments & Products:** Payment methods and product category analysis.
- **Data Quality:** Missing values, duplicates, and data quality checks.

## Technology Stack

- Python
- Pandas
- Plotly
- Streamlit
- CSV datasets

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.

Dataset: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

The dataset includes customer, order, product, seller, payment, review, and geolocation information.

## Installation and Usage

**1. Clone the repository**

```bash
git clone https://github.com/wd369018/Olist-E-Commerce-Analytics-Dashboard.git
```

**2. Navigate to the project directory**

```bash
cd Olist-E-Commerce-Analytics-Dashboard
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
python -m streamlit run app.py
```

## Streamlit Community Cloud

Use Python 3.12 (the Community Cloud default). The project pins Streamlit 1.56.0 to retain its Tornado-based default server; Streamlit 1.57 changed the default to Starlette, which is avoided due to reported ASGI startup and health-check failures.
